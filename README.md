# Agent Commons

Agent Commons is a proposed open marketplace for agentic tools and a
community-led home for AI and agent specifications. It aims to work across
platforms, operating systems, agent harnesses, and model providers.

This repository currently contains **proposals, not an implementation or an
adopted standard**. No board has been elected. Interoperability and standards
compliance must be demonstrated by published conformance tests; they are not
assumed.

## Proposals

- [Architecture](docs/architecture.md): marketplace, interfaces, agent
  orchestration, security, and delivery milestones.
- [Governance](docs/governance.md): a proposed contributor-elected board and
  process for AI and agent specifications.

The initial milestone is to review these proposals before implementation.
Licensing, legal structure, membership criteria, and the initial election
require community decisions. Participation and proposals should be public,
except for sensitive security reports and private election records.
